# Archive de la version originale de Jour1.pdf

Le fichier `Jour1.pdf` à la racine du projet a été **écrasé** par l'export du
nouveau deck Slidev. Ce dossier contient tout ce qui avait été extrait du PDF
original avant cet écrasement :

- `pages/p01.png` … `p29.png` : les 29 pages rendues à 90 dpi (900 x 506 px)
- `Jour1-original-rendu.pdf` : ces mêmes pages assemblées en PDF
  (image seulement, texte non sélectionnable, qualité limitée à 90 dpi)
- `images/` : les 68 images embarquées dans le PDF, à leur résolution native
  (logos, avatars, graphiques, captures d'écran)

Ce n'est donc pas une copie fidèle du fichier d'origine : c'est la meilleure
reconstitution possible à partir de ce qui avait été extrait.

Le contenu textuel intégral des 29 pages a été repris tel quel dans
`../slides.md`.
